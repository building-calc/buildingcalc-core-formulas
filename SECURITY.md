# Security Policy

## Reporting a vulnerability

If you discover a security issue affecting this repository, please avoid publishing sensitive details in a public issue before the maintainer has had an opportunity to investigate.

Use GitHub's private vulnerability reporting feature if it is enabled for this repository. Otherwise, contact the maintainer through a verified contact method published on the official BuildingCalc website.

Please include:

- A concise description of the issue.
- The affected file, function, or version.
- Steps to reproduce the issue.
- The potential impact.
- Any suggested mitigation, if known.

## Scope

This repository contains mathematical utilities and related documentation. Reports may concern unsafe input handling, dependency vulnerabilities, unintended data exposure, or defects that affect the integrity of calculation outputs.

## Response

The maintainer will review reports as time and available information permit. Please do not assume a particular response time or a guaranteed fix.

Thank you for helping improve the security and reliability of the project.
