# Contributing to BuildingCalc Core Formulas

Thank you for your interest in improving BuildingCalc Core Formulas.

We welcome focused contributions that improve mathematical correctness, input validation, unit clarity, documentation, and test coverage.

## Before making a change

- Check existing functions and documentation to avoid duplicating work.
- Confirm the units expected by each input and returned value.
- Identify the mathematical formula and assumptions.
- Use reliable references when a calculation depends on a technical standard.
- Do not describe an estimate as certified or code-compliant without appropriate verification.

## Contribution process

1. Open an issue describing the proposed change or problem.
2. Explain the formula, units, assumptions, and expected behaviour.
3. Create a branch for the change.
4. Implement the smallest reasonable change.
5. Add or update tests for normal, boundary, and invalid inputs.
6. Update documentation and examples.
7. Submit a pull request explaining what changed and how it was tested.

## Code quality

- Prefer clear names and small, focused functions.
- Document units and return values.
- Avoid hidden assumptions and unexplained constants.
- Handle invalid numeric inputs consistently.
- Keep examples consistent with the actual implementation.
- Do not include credentials, personal data, or proprietary source code.

## Review

Contributions may be reviewed for correctness, maintainability, scope, documentation, and test coverage. A submitted change is not considered accepted until it has been reviewed and merged by a maintainer.

Thank you for helping make construction calculation utilities more transparent and reliable.
